# QED diagram studio

[README_en.md](.\README.md) 

電子・陽電子・光子の入出力外線数、QED頂点数、ループ次数から、連結ファインマン図の代表例を生成するStreamlitアプリです。


![qed_diagrams_all](.\qed_diagrams_all_2loop.png)

## 起動

```powershell
.\.venv\Scripts\streamlit.exe run streamlit_app.py
```

ブラウザで `http://localhost:8501` を開きます。

## 現在の範囲

- 電子 `e⁻`、陽電子 `e⁺`、光子 `γ`
- 電荷保存と指定ループ次数を検証
- 1粒子既約（1PI）図だけを採用
- Furryの定理により奇数光子頂点の閉フェルミオンループを除外
- 厳密なグラフ同型判定で重複を除去
- オープンソースの `feynman` 2.1.1で描画
- `pyfeyn2` 2.4.3のFeynML構造と自動ベンド判定を使用
- 内部光子を上下の独立レーンへ割り当てて重なりを防止
- 頂点数またはループ次数の片方だけを入力し、もう片方を自動計算
- 各頂点は電子線2本と光子線1本
- 自己ループを除く連結図
- 大きな入力では全列挙ではなく、重複を除いた代表例を最大24件生成

## 1PIの定義

任意の内部プロパゲータを1本除いても連結性が保たれる図だけを採用します。そのため、内部線を切ると二つに分かれる通常の交換型ツリー図は表示されません。
